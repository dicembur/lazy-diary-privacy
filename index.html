Lazy Diary 개인정보 처리방침

시행일: 2026년 10월 24일

Lazy Diary(이하 "앱")는 사용자의 개인정보를 수집하거나 외부로 전송하지 않습니다. 이 문서는 앱이 어떤 데이터를 어떻게 다루는지 설명합니다.

1. 수집하는 개인정보

앱은 개인정보를 수집하지 않습니다. 회원가입과 로그인이 없고, 이름, 이메일, 연락처, 위치, 기기 식별자 등을 요구하지 않습니다.

2. 사용자가 작성한 기록

  • 사용자가 작성한 일기 내용과 날짜, 시간은 사용자의 기기 안에만 저장됩니다.
  • 개발자의 서버나 제3자 서버로 전송되지 않으며, 개발자는 이 기록에 접근할 수 없습니다.
  • 인터넷 연결 없이 동작합니다.

3. 분석 도구와 광고

앱에는 사용 통계 분석 도구, 광고 SDK, 추적 기술이 포함되어 있지 않습니다.

4. 백업 파일

  • 설정 화면의 "데이터 내보내기"를 사용자가 직접 실행한 경우에만 백업 파일(JSON)이 만들어집니다.
  • 백업 파일을 어디에 저장하거나 누구와 공유할지는 사용자가 직접 선택하며, 보관과 관리의 책임은 사용자에게 있습니다.
  • 복원 시 사용자가 선택한 파일만 읽으며, 이 파일은 외부로 전송되지 않습니다.

5. 기기 백업

기기 설정에 따라 iCloud 백업이나 컴퓨터 백업에 앱 데이터가 포함될 수 있습니다. 이는 사용자의 운영체제(Apple)가 제공하는 기능이며 앱이 별도로 전송하는 것이 아닙니다.

6. 데이터 삭제

앱을 삭제하면 기기에 저장된 기록이 함께 삭제됩니다. 앱 안에서 개별 기록을 삭제할 수도 있습니다. 이미 내보낸 백업 파일은 사용자가 직접 삭제해야 합니다.

7. 아동의 개인정보

앱은 연령과 관계없이 개인정보를 수집하지 않습니다.

8. 방침의 변경

이 방침이 변경되면 이 페이지에 새 시행일과 함께 게시합니다.
